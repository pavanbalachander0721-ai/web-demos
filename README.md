# Web demos

Concept websites I designed and built for local businesses in Kengeri, Bengaluru. Each site tells one story that plays out as you scroll, and it is built to work on phones as well as laptops.

|---|---|---|---|

## How they're built

- Single-file HTML, CSS and JavaScript with no build step
- GSAP and ScrollTrigger for scroll-scrubbed timelines, and Lenis for smooth scrolling
- Hand-written SVG illustrations, animated in code
- Live opening hours worked out in Indian time, with Google Maps embeds and pre-filled WhatsApp messages
- Respects `prefers-reduced-motion`: the story still plays, just more calmly. If the animation library fails to load, the page shows a plain static layout instead.
- Tested on phone, laptop and large-screen sizes

These are unofficial concept previews, marked as such on every page and excluded from search engines. All business details come from public listings.
